<h1>RecipesApp</h1>
🌐 Live App: <a href="https://recipes-app-five-sand.vercel.app/" target="_blank">Recipes App</a>
<br></br>
<p>Features: ✨</p>

✅ Discover multiple creative recipes!

✅ Choose ingredients you already have at home!

✅ Customize meals by calories and protein goals!

✅ Save your favorite recipes to cook again later!

Installation ⚙️

Clone or download the repository.

Navigate to the project folder in your editor.

Run **npm install** to install all dependencies.

Run Project: npm run dev
